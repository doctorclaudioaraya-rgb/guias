# Sistema Despertar

App de misiones diarias para adultos con TDAH que acompaña al curso/taller de alto rendimiento del Dr. Claudio Araya.
Inspirada en la estructura del "Sistema" de un anime de cazadores y en las reglas de Barkley para el TDAH adulto.

Estado: **diseño v0.6**. Todavía no hay código de la app.
